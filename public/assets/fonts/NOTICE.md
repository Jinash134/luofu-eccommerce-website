# Switzer

Designer/foundry: Indian Type Foundry, via Fontshare.

Original, unmodified WOFF2 files for weights 400, 500, 600 and 700, downloaded from the official Fontshare API on 24 September 2026.

- Typeface: https://www.fontshare.com/fonts/switzer
- Licence: https://www.fontshare.com/licenses/itf-ffl
- Source CSS: https://api.fontshare.com/v2/css?f[]=switzer@400,500,600,700&display=swap

The current ITF Free Font License permits self-hosting for the licensee's own website. These files are used only as this site's webfonts; they are not a font distribution or editing service. Do not modify, subset, rename or convert the font files.

Switzer supplies Latin glyphs. The shared CSS stack includes a system fallback for Arabic characters and for loading failures.
